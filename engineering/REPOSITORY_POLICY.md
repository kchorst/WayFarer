# Repository / Release Policy

- `main` is the persistent source of truth.
- No release claim is made from chat state or an ad-hoc ZIP.
- Development builds are not RCs.
- Every discovered P0/P1 maps to a general invariant and unrelated regression coverage.
- Fixed named itineraries never constitute global proof.
- Mocked rendered tests are behavioral tests, not proof of live local-model success.
- Release evidence must identify the exact source commit and exact ZIP SHA-256.
- Any source change after evidence invalidates that evidence.
- The traveler performs final acceptance, never primary QA.
